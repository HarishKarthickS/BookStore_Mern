# BookStore_Mern

**Archive / learning repo.** This is not a MERN stack. There is no Mongo, Express, or Node API here — it is a Vite + React + MUI catalog UI that talks to a public teaching books API. The library product to look at is [LuminaLib](https://github.com/HarishKarthickS/LuminaLib).

A bookstore web app built with React and Vite.

## Run

```bash
npm install
npm run dev
```

## Stack

React, Vite, Material UI
